# User-facing features — last ~3 weeks

**Audience:** What we shipped for learners and instructors (not technical implementation).  
**Product:** Neural Network Playground — learning path, quizzes, tutor, builder, and classic visualization lab.

---

## Learning path & progress

- **Clearer chapter progress:** Finishing the lesson materials counts for half of a chapter; finishing that chapter’s quiz counts for the other half. The same percentage and status show on **Learn**, each **lesson page**, **Quiz**, and **Profile** so nothing feels out of sync.
- **Honest “completed” chapters:** A chapter only fully counts as done when both the materials side and the quiz side are satisfied. If you’ve only done one part, the app explains that you still need the quiz (or materials) instead of looking 100% done everywhere.
- **Profile overview:** You see **overall course-style progress**, how many chapters are fully finished, and a **per-module progress %** plus clearer status words (e.g. needs quiz, needs materials, done).

---

## AI tutor

- **More reliable answers:** The tutor is less likely to show a vague “unavailable” message when something else is wrong (e.g. server not running, bad connection). When something fails, you often get a **clearer explanation** of what went wrong.
- **Smoother chat:** Fixes so the tutor doesn’t get confused by duplicate messages and works more predictably from the **Tutor** page and the **Ask tutor** panel on lessons.

---

## How it works

- **Horizontal journey:** The five steps (concept → build → visualize → quiz → recommendations) are shown **in a row** so the flow reads left-to-right like a timeline; on phones you can **scroll sideways** through the steps.
- **Picture for every step:** Each step has its own image, including a **dedicated quiz visual** so the “Take quiz” step always looks complete and clear.

---

## Home (landing)

- **Hero image:** Updated to match the product — **AI / deep learning** style imagery instead of unrelated stock photos.
- **Quiz entry on home:** The **Take a Quiz** shortcut uses the same reliable quiz artwork so that card always shows a proper graphic.

---

## Classic Network Playground (2D training lab)

- **Cleaner experience:** Removed extra **GitHub** links from that page so the focus stays on learning.
- **Better on phones:** The page respects normal mobile screen width instead of forcing a desktop-only width.
- **Layers you can control:** The **add / remove hidden layer** controls are visible again so you can change network depth from the UI.
- **Readable training readout:** **Test loss** and **training loss** are easy to read on the dark theme, and the **output** area isn’t cut off so you can see metrics and the visualization together.

---

## Network Builder

- **Faster layer edits:** You can **add a hidden layer** or **remove the last hidden layer** with buttons in the sidebar, not only by dragging — handy when you’re iterating on architecture.

---

## Navigation & account

- **Profile in reach:** When you’re signed in, your **profile** shortcut sits **next to the light/dark mode** control so account and theme are in one place.
- **Profile page:** Slightly more comfortable spacing and layout on the account/progress screen.

---

## Language & accessibility of messages

- New and updated **English** (and some **Chinese**) text for progress states, tutor errors, and chapter completion hints so explanations match the new rules.

---

## Mobile & small screens

- Less horizontal awkwardness on narrow screens; **How it works** scrolls naturally; **Profile** table actions are easier to tap on a phone.
