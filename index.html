Neural Network Playground

This project helps you understand how neural networks learn. You can build a small network with a visual editor, connect layers and activation functions, attach a dataset, and run training — all in the browser, with no code.

Use the Network Builder to design your architecture: add a dataset node, add one or more hidden layers (each with a chosen number of neurons and activation function), connect them to an output node, then start training. The playground will show how the model learns to fit or classify the data.
