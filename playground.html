How to use this page

Configure layers and activations in the Network Builder, then use this lab: pick a dataset, adjust noise and batch size, and press play to watch the decision boundary evolve.

Playback

  • Reset clears the run; Play / Pause trains or stops; Step advances one epoch at a time.
  • Watch training and test loss in the output column—aim for both to decrease without the training loss diving far below test loss (overfitting).

Network shape

  • Hidden layers: use + / − next to the layer count in the middle column to add or remove a layer.
  • Neurons per layer: above each hidden column in the diagram, use the + and − buttons to add or remove neurons in that layer (1–8 each).

Reading the visualization

  • Colors show how the network classifies regions of the plane; the heatmap and neuron thumbnails explain which features matter.
  • Toggle test data and discretize output to compare raw scores with hard class labels.

Tip: If you need to change learning rate, regularization, or problem type (classification vs regression), do it in the Network Builder so your settings stay consistent across the course workflow.
