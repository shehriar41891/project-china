Neural Network Playground

About

This Neural Network Playground is an educational tool to explore how neural networks learn. You can design a small feedforward network using a node-graph editor: add a dataset, add hidden layers with a chosen number of neurons and activation function, connect them to an output, and run training. Results are shown in the classic playground view (loss curves and decision boundary).

The project is based on the TensorFlow Playground by Daniel Smilkov and Shan Carter. This version adds a visual node-graph builder, multi-language support (English, Chinese, Japanese), and a clearer flow from building the network to running training.
